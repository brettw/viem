# Flightline Code fonts

The bundled regular and italic variable fonts identify themselves as
`Flightline Code`, `Version 0.002`. Both files are byte-identical to the
[Flightline distribution at efb94277da72f1402eb057a07e9f295077813027](https://github.com/brettw/flightline/tree/efb94277da72f1402eb057a07e9f295077813027/ttf/variable).

Flightline is derived from [B612](https://github.com/polarsys/b612), and its
distribution README attributes the Powerline, box drawing, geometric, braille,
and large type glyphs to [Cascadia Code](https://github.com/microsoft/cascadia-code).

| Document | Scope |
| --- | --- |
| [OFL.txt](OFL.txt) | The bundled SIL Open Font License 1.1, with B612's copyright notice. Both font binaries also identify OFL 1.1 in name-table records 13 and 14. |
| [Cascadia-Code-LICENSE.txt](Cascadia-Code-LICENSE.txt) | Cascadia Code's OFL 1.1 notice, including its reserved font name. |
| [EPL-2.0.html](EPL-2.0.html) and [EDL-1.0.html](EDL-1.0.html) | Additional license documents included by Flightline upstream and referenced in its distribution README. |
| [FONT-NOTICES.txt](FONT-NOTICES.txt) | Exact copyright, trademark, designer, version, and licensing strings extracted from both bundled font binaries. |
| [TRADEMARKS.md](TRADEMARKS.md) | B612 / PolarSys trademark notice. |
| [AUTHORS.txt](AUTHORS.txt) and [CONTRIBUTORS.txt](CONTRIBUTORS.txt) | Upstream attribution lists. |
| [UPSTREAM-README.md](UPSTREAM-README.md) | Unmodified bundled README, including its copyright and licensing statements. Its relative image/document links refer to the upstream Flightline repository. |

The README's Microsoft copyright range is `2026–2026`; the actual font binaries
say `2019–2026`. Both are retained without changing the source distribution.
The font metadata and OFL file identify the font license; the additional EPL
and EDL documents are retained because the distribution references them, without
recasting those statements as a choice of license for the font binaries.

Original files remain under [assets/fonts/flightline](../../../../assets/fonts/flightline).
Exact source URLs and checksums are in [sources.json](../sources.json).
