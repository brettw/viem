# Front matter in Markdown Preview

The metadata above uses Code Block styling with YAML highlighting. Its language
label reads **front matter** and the language picker is disabled. Preview hides
the opening and closing `---` lines; turn Preview off to see them in Code mode.

You can edit the YAML body in Preview, including comments, indentation and
quoting. It stays literal while you type and has no effect on Viem's settings.
Create a new front-matter block by entering its delimiters at the beginning of
the document in Code mode.
